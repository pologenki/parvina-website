# Pologenki website

Многоязычный сайт на Vite: английский (`/`), русский (`/ru/`) и китайский (`/zh-cn/`).

## Локальный запуск

```sh
npm ci
npm run dev
```

Команда `npm run build` создаёт готовый сайт в `dist/`. Для проверки этой сборки используйте `npm run preview`.

## Структура

- `src/main.js` — единый запуск компонентов и переключение языка.
- `src/components/` — каталог, первый экран, услуги, галерея, контакты и футер.
- `src/utils/` — переводы, аналитика, блокировка прокрутки и обработка формы.
- `src/css/base.css` — общие стили; оформление компонентов находится в отдельных CSS-файлах рядом.
- `src/utils/product-offers.js` — стартовая цена из цен сортов; общий рендер таблицы используется также на страницах товаров.
- `src/locales/` — переводы интерфейса.
- `public/data/` — товары, цены и записи галереи.
- `public/admin/index.html`, `admin.css`, `admin.js` — разметка, стили и логика админки.
- `public/admin/price-import*.js` — импорт цен из Excel и CSV.
- `scripts/` — обработка изображений, генерация страниц и проверки данных/SEO.

`admin.js` подключается как обычный скрипт: существующие кнопки админки используют его глобальные обработчики. Модуль импорта цен подключается после него.

## Проверки

```sh
npm run validate:data
npm run test:price-import
npm run test:offers
npm run test:catalog-search
npm run build
```

Сборка создаёт адаптивные изображения и страницы товаров/услуг для всех языков, затем проверяет SEO. Исходные фотографии нужны для повторной обработки и работы админки; папки `public/optimized/` и сгенерированные страницы не редактируются вручную.

При изменении интерфейса проверяйте компьютер и телефон, все три языка, поиск, модальные окна, форму запроса и свайпы услуг. При изменении админки проверяйте предварительный просмотр импорта и публикацию цен без записи тестовых данных в настоящий репозиторий.

## Публикация

После отправки изменений в `master` GitHub Actions проверяет данные и импорт цен, собирает сайт и публикует `dist/` через GitHub Pages. Цены редактируются в админке и сохраняются в `public/data/products.json` с историей изменений и датой обновления.
