Основные цвета, используемые на сайте:

1. Черный (#000, #00000) - используется для:
   - Текстов, заголовков
   - Фона элементов при наведении
   - Границ элементов
   - Кнопок и иконок

2. Белый (#fff, #ffffff) - используется для:
   - Фона страниц и блоков
   - Текста на темном фоне
   - Иконок и текста при наведении

3. Синий (#66b1f1) - используется для:
   - Кнопки "Let's talk" и других интерактивных элементов
   - Акцентов и галочек в списках
   - Обводки кнопок при фокусе

4. Темно-синий (#5590d1) - используется для:
   - Эффектов при наведении на синие элементы

5. Серые оттенки:
   - #333 - для заголовков
   - #666 - для второстепенного текста
   - #555 - для основного текста
   - #f8f9fa - для фона некоторых секций
   - #e0e0e0 - для разделителей
   - #f0f0f0 - для границ
   - #b0b0b0 - для пагинации
   - #7f8c8d - для дат

6. Цвета социальных сетей:
   - #1877f2 (Facebook)
   - #0088cc (Telegram)
   - #25d366 (WhatsApp)
   - #ea4335 (Gmail)
   - #09b83e (WeChat)

7. Дополнительные акцентные цвета:
   - #4CAF50 (зеленый для уведомлений)
   - #f4436 (красный для ошибок)
   - #e67e22 (оранжевый для кнопок)
   - #85c1f4 (голубой для оверлея)
   - #2ecc71 (зеленый для бейджей)
   - #ff6b35 (оранжевый для бейджей)

Основная цветовая палитра сайта выполнена в черно-белых тонах с синими акцентами.
